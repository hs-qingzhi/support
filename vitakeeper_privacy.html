康护APP隐私政策

隐私政策
🔒 最后更新：2026年08月03日

康护APP是一款健康管理应用，用于记录血压、血糖、血脂和BMI数据，提供健康提醒、家庭成员管理、数据统计分析、OCR图片识别等功能。我们十分尊重您的个人信息和健康数据，并会尽全力保护您的信息安全。本隐私政策根据相关法律法规制定，明确说明我们如何收集、使用、存储和保护您的信息。

在您阅读本隐私政策并点击「同意并继续」之前，我们以及本政策列明的任何第三方 SDK 均不会收集您的任何个人信息、不会申请任何系统权限、不会读取设备标识符。所有统计、推送、广告、崩溃监控等第三方服务均在您同意之后才会初始化。

如果您是未满 14 周岁的儿童，或您是儿童的父母/其他监护人，请另行阅读《康护 APP 未成年人个人信息保护规则》：https://hs-qingzhi.github.io/support/vitakeeper_minor_privacy.html

📊一、收集信息的方式和范围

  • 1.1 健康数据收集：在您使用康护APP记录血压、血糖、血脂和BMI等健康信息时，我们会收集相关数据用于健康分析、趋势提醒和报告生成。您可以随时在APP中查看、修改或删除自己的健康数据。
  • 1.2 基本设备信息：为了提供更稳定和个性化的服务，我们可能会在您同意隐私政策后收集设备硬件信息（如设备型号、操作系统版本等）及网络信息（如 IP 地址、网络类型），用于统计、安全风控和优化服务体验。
  • 1.3 第三方服务使用：部分功能依赖第三方服务来实现。只有在您同意隐私政策后，相关服务才会运行。具体包括：
    • 友盟统计服务（Umeng）：用于 APP 使用情况统计、性能优化与崩溃监控。服务收集设备信息（设备型号、操作系统版本、网络类型、IP 地址、传感器列表、AndroidID）和事件数据（如功能使用、订阅转化、付费墙触达），但不会收集您的健康数据明细。
    • 友盟推送服务（Umeng Push）：用于向您发送健康提醒和重要通知，使用 APNs/Push token 等设备识别信息。
    • 阿里云消息通道 ACCS（包名 com.taobao.accs，由上述友盟推送 SDK 内嵌集成，仅国内渠道）：用于维持推送长连接、保证健康提醒能及时送达。为判断连接可用性与选择接入点，该通道会读取网络状态信息（网络连接状态、网络类型如 WIFI/移动网络、是否漫游）及 IP 地址。不收集您的健康数据。
    • Google Play 服务（Google Mobile Services，Google 提供）（同上，仅 iOS 版与 Google Play 版启用）：为 Firebase 推送与 Google AdMob 广告提供基础运行环境。会读取已安装应用信息（仅查询 Google Play 商店组件 com.android.vending 的版本，用于判断服务可用性）及设备识别信息。该服务仅在您同意本隐私政策后才会被启动。
    • 移动安全联盟 MSA SDK（包名 com.bun.miitmdid，仅国内渠道）：由广告 SDK 依赖集成，用于获取匿名设备标识符 OAID/VAID/AAID，替代 IMEI 等不可变更的硬件标识，供广告归因与反作弊使用。您可在系统设置中重置该标识。
    • 百度 OCR 服务（Baidu Cloud OCR）：用于识别血压计、血糖仪等健康设备屏幕上的数据。当您使用拍照识别功能时，您拍摄的照片会上传至百度云服务器进行 OCR 处理，识别完成后图片不会保留在我们的服务器，但请避免在照片中包含与健康设备无关的敏感信息（如身份证、面部、银行卡等）。
    • Firebase（Google 提供）（仅 iOS 版与 Google Play 版启用；华为、荣耀、小米、OPPO、vivo、应用宝等国内安卓渠道包不启用）：包括 Firebase Cloud Messaging（推送通知）和 Firebase Remote Config（远程配置）。可能收集设备识别信息、IP 地址和 App 安装信息。该服务由境外主体处理，涉及个人信息跨境提供，详见「1.5 个人信息的跨境提供」。
    • Google AdMob 广告 SDK（仅国际版/海外渠道）：在免费用户开屏页展示广告。AdMob 可能收集广告标识符（IDFA / IDFV）、IP 地址、设备信息和广告交互数据。订阅 Premium 用户不会展示广告。
    • 字节跳动穿山甲（Pangle / GroMore 聚合）SDK（仅国内渠道）：在免费用户开屏页展示广告。可能收集网络信息（IP 地址）、传感器信息（传感器列表，用于广告反作弊与设备识别）及设备标识信息（OAID 等；MAC/IMEI 已禁用，仅基础识别）。订阅 Premium 用户不会展示广告。
    • HTTPDNS-android（开发者：杭州阿里云智能科技有限公司，仅国内渠道）：由统计/推送等第三方 SDK 依赖集成，用于域名解析优化、防止 DNS 劫持，保障网络请求的稳定与安全。可能收集网络信息（IP 地址）。SDK 隐私政策：https://terms.aliyun.com/legal-agreement/terms/suit_bu1_ali_cloud/suit_bu1_ali_cloud202112071754_83380.html
    • App 内购买（StoreKit）：通过 Apple 提供的 In-App Purchase 框架处理订阅与支付，由 Apple 直接管理交易；我们仅接收订阅状态和到期时间，不接触您的支付凭据。
    • 支付宝（Alipay）APP 支付 SDK（仅国内安卓渠道）：用于安卓端会员开通的支付宝下单与收银台调起（一次性购买，到期不自动续费）。该 SDK 由支付宝（中国）网络技术有限公司提供，为完成交易、风控与防欺诈，可能收集设备信息与设备标识符（如 OAID 及设备指纹相关信息），并探测您的设备是否已安装支付宝客户端；我们不接触您的支付宝账户密码、银行卡号等支付凭据。其个人信息处理以支付宝官方隐私政策为准。
  • 1.4 用户反馈与投诉：您可以在APP“我的”页面中的“问题反馈”功能提交反馈或投诉，涉及个人信息或健康数据时，我们会严格按照隐私政策处理。
  • 1.5 个人信息的跨境提供
    • 适用范围：仅 iOS 版与 Google Play 版存在跨境提供。华为、荣耀、小米、OPPO、vivo、应用宝、360、百度、豌豆荚等国内安卓渠道包不集成启用 Google 服务，不向境外提供任何个人信息。
    • 境外接收方：Google LLC（注册地：美国加利福尼亚州）。
    • 联系方式：https://support.google.com/policies；隐私政策 https://policies.google.com/privacy
    • 处理目的：下发推送通知（Firebase Cloud Messaging）、获取版本更新等远程配置（Firebase Remote Config）、投放与结算广告（Google AdMob，仅免费用户）。
    • 处理方式：由 Google 在其境外服务器接收并处理。
    • 个人信息种类：设备识别信息、IP 地址、App 安装信息、广告标识符（IDFA / IDFV）。不包含您的健康数据、成员资料与手机号。
    • 您的权利：您可通过在系统设置中关闭通知权限、订阅 Premium（不再展示广告）或卸载 App 撤回上述跨境提供；也可发送邮件至 1558406139@qq.com 要求我们停止。

  • 提供健康数据记录、分析与趋势提醒服务。
  • 优化产品功能与用户体验，包括性能监控与稳定性改进。
  • 向您发送重要健康提醒、服务通知与必要的运营消息。

🛡️三、信息存储与保护

  • 健康数据会加密存储，并采取合理的技术措施防止未经授权的访问、泄露或篡改。
  • 严格限制员工对个人信息的访问权限，仅授权必要岗位处理相关数据。
  • 定期开展安全审计与漏洞检测，及时修复安全问题并加强防护。
  • 我们承诺不向无关第三方出售、共享或泄露您的健康数据，除非法律法规要求或为保障用户安全。
  • 安全声明：我们采取合理、必要的技术与管理措施，但无法保证信息绝对安全。用户理解并同意，因不可抗力、第三方原因或用户自身原因导致的数据丢失、泄露或损坏，公司在法律允许范围内不承担赔偿责任。

🔐四、设备权限使用说明

我们会在必要时向您申请以下设备权限，您可以选择同意或拒绝授权：

  • 4.1 相机权限
    • 用途：①为家庭成员拍摄头像照片，方便识别和管理不同成员的健康数据；②在记录血压、血糖、血脂时，拍照识别（OCR）血压计、血糖仪等设备屏幕上的读数，便于快速录入。
    • 使用场景：仅在您点击“添加成员 → 拍照”，或在记录表单中使用“拍照识别”功能时申请。
    • 您的选择：您可以拒绝授权并改用手动输入，或从相册选择照片。
  • 4.2 通知权限
    • 用途：发送健康数据记录提醒、用药提醒等健康管理通知，帮助您保持健康习惯。
    • 使用场景：仅在您主动设置提醒时使用。
    • 您的选择：您可以随时在系统设置中关闭通知权限。
  • 4.3 隐私保护承诺
    • ✅ 康护APP不会申请存储权限，照片均通过系统相册选择器完成，保护您的文件隐私。
    • ✅ 健康数据默认仅保存在您的设备本地；仅当您主动开启“云备份”功能时，相关健康数据才会通过加密通道（HTTPS）上传至我们的服务器，用于备份与多设备同步，您可随时关闭云备份并删除云端数据。
    • ✅ 我们不会收集您的位置信息、通讯录、通话记录等敏感信息。

⚖️五、您的权利与行使方式

您对自己的个人信息享有以下权利。以下每项权利在 App 内均有对应的操作入口，无需联系客服、无需付费、无需提供身份证件或手持照片等额外材料。

  • 5.1 查阅与更正
    • 健康数据：在「首页」或各记录列表中点击任一条血压、血糖、血脂、BMI 记录即可查阅并修改。
    • 成员资料（姓名、性别、生日、头像）：「我的 → 成员管理 → 点击成员」即可编辑。
    • 账号信息（手机号、注册时间、用户 ID）：「我的 → 账号管理」可查阅。
    • 数据副本：「我的 → 账号管理 → 数据管理 → 导出数据」，可将您的全部健康数据导出留存。
  • 5.2 删除个人信息
    • 单条健康记录：点击该条记录打开详情，点击右上角「删除」按钮，即时生效。
    • 成员及其全部记录：「我的 → 成员管理 → 删除成员」，该成员名下的健康记录一并删除，即时生效。
    • 云端备份数据：「我的 → 账号管理 → 数据管理 → 云备份 → 删除云端数据」，服务器上已备份的健康数据将被永久删除，本机数据不受影响。
    • 反馈内容与图片：「我的 → 其他 → 意见反馈 → 我的反馈」中删除，记录即时移除、图片随后清理。
    • 若您通过上述入口无法完成删除，可发送邮件至 1558406139@qq.com，我们将在 15 个工作日内核查并完成处理。
  • 5.3 注销账号
    • 操作路径：「我的 → 点击顶部账号卡片 → 账号管理 → 删除账号」。
    • 唯一条件：为防止他人恶意注销您的账号，需输入本账号绑定的手机号并通过短信验证码完成身份核验。除此之外我们不设置任何其他条件。
    • 处理结果：验证通过后账号即时注销，App 自动退出登录；您的账号信息、云端备份的健康数据、订阅关联记录将在服务器后台一并删除或匿名化，不作保留，账号不可恢复。若因系统异常导致后台未能同步完成，我们将在15 个工作日内完成核查与清除。
    • 注销前请先使用「导出数据」自行备份，注销后数据无法找回。
  • 5.4 撤回同意
    • 撤回对本隐私政策的整体同意：卸载 App 即视为撤回；或发送邮件至 1558406139@qq.com 声明撤回，我们将在 15 个工作日内停止对应处理活动。
    • 撤回相机权限：手机「系统设置 → 应用管理 → 康护 → 权限 → 相机 → 关闭」，关闭后仍可手动输入数据。
    • 撤回通知权限：手机「系统设置 → 应用管理 → 康护 → 通知 → 关闭」，或在「我的 → 健康提醒」中关闭提醒。
    • 撤回云端存储授权：「我的 → 账号管理 → 数据管理 → 云备份 → 关闭云备份状态开关」，关闭后不再上传，健康数据仅保存在本机；如需一并清除已上传的副本，请使用同页的「删除云端数据」。
    • 撤回广告个性化：订阅 Premium 后不再展示任何广告；也可在手机「系统设置 → 隐私 → 广告」中重置或关闭广告标识符（OAID）。
    • 撤回同意不影响撤回前基于您的同意已进行的个人信息处理活动的效力。撤回部分授权可能导致相应功能不可用，但不影响 App 基础的本地健康记录功能。
  • 5.5 响应时限承诺：对于 App 内可直接操作的更正、删除、注销请求，均即时生效；对于需人工处理的请求（含邮件提交的删除、注销、撤回同意、查阅副本请求），我们承诺在收到请求之日起 15 个工作日内完成核查与处理并向您反馈结果。
  • 5.6 投诉与举报：如您认为我们的个人信息处理行为损害了您的合法权益，可通过「我的 → 其他 → 意见反馈」提交，或发送邮件至 1558406139@qq.com，我们将在 15 个工作日内答复。若您对答复不满意，可向所在地网信、电信、公安、市场监管等主管部门投诉举报，或向有管辖权的人民法院提起诉讼。
  • 5.7 未成年人：我们为不满 14 周岁的儿童制定了专门的个人信息处理规则，详见《康护 APP 未成年人个人信息保护规则》：https://hs-qingzhi.github.io/support/vitakeeper_minor_privacy.html（也可在「我的 → 其他 → 未成年人隐私政策」中查看）。

💬九、意见反馈功能的信息处理

当您使用 App 内「意见与反馈」时，我们会收集并处理以下信息，仅用于接收与处理您的反馈、与您沟通、改进产品：

  • 9.1 您主动提供的信息：反馈内容、图片、联系方式（选填）。其中联系方式经加密后存储。
  • 9.2 为定位问题自动附带的信息：App 版本、系统版本、设备型号、语言、会员状态、所在页面，以及一个匿名设备标识（不含您的姓名、手机号等真实身份）；提交时还会记录访问 IP，仅用于防滥用与安全防护，不作长期留存。

  • 9.5 您的权利：您可在「我的反馈」内删除您的全部反馈（连同图片），提交后即时移除记录、图片随后清理。
  • 9.6 非公开：本渠道为您与开发者之间的非公开支持工单，内容不会公开展示给其他用户。
