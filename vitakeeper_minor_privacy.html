康护APP未成年人个人信息保护规则

儿童及未成年人隐私政策
🔒 最后更新：2026年08月03日　|　生效日期：2026年08月03日

本规则是衡水青智科技有限公司（以下简称"我们"）依据《中华人民共和国个人信息保护法》第三十一条、《儿童个人信息网络保护规定》第八条制定的专门的未成年人个人信息处理规则，是《康护APP隐私政策》不可分割的组成部分。就未成年人个人信息的处理，本规则与《康护APP隐私政策》不一致的，以本规则为准。

👶一、适用对象

  • 1.1 儿童：指不满 14 周岁的未成年人。处理儿童个人信息，适用本规则的全部条款。
  • 1.2 其他未成年人：指已满 14 周岁、不满 18 周岁的未成年人。我们参照本规则对其个人信息予以同等保护。
  • 1.3 监护人：指未成年人的父母或者其他依法负有监护职责的人。
  • 1.4 定位说明：康护 APP 面向成年人设计，不面向儿童单独提供服务。儿童的健康数据只可能由其监护人在"成员管理"中作为家庭成员代为录入。

✅二、监护人同意

  • 2.1 单独同意：如您是儿童本人，请在监护人的陪同下阅读本规则，并务必请监护人代为作出是否同意的决定；未取得监护人同意，请勿使用本 APP。
  • 2.2 代为录入的确认：如您是监护人，当您在「我的 → 成员管理 → 添加成员」中为儿童建立成员档案并录入其健康数据时，即视为您已阅读本规则并同意我们按本规则处理该儿童的个人信息。
  • 2.3 拒绝的后果：您有权拒绝。拒绝后，您仍可正常使用 APP 为自己或其他成年成员记录健康数据，仅无法为该儿童建立成员档案。
  • 2.4 撤回同意：监护人可随时撤回同意，方式见本规则第六条。

📋三、收集范围、目的与方式

我们坚持最小必要原则，仅收集为实现健康记录功能所必需的儿童个人信息：

  • 3.1 成员档案信息
    • 收集内容：昵称或姓名、性别、出生日期、头像（选填）。
    • 目的：区分不同家庭成员的健康数据，并按年龄段套用相应的血压/血糖参考区间。
    • 方式：由监护人在成员管理页手动填写，我们不通过任何其他渠道获取。
  • 3.2 健康数据
    • 收集内容：血压、血糖、血脂、身高体重及 BMI 记录及其记录时间、备注。
    • 目的：生成健康趋势图表与提醒。
    • 方式：由监护人手动输入，或使用相机拍摄血压计/血糖仪屏幕后通过 OCR 识别读数。
  • 3.3 我们明确不收集的信息：我们不收集儿童的身份证号、住址、学校信息、位置信息、通讯录、通话记录、生物识别特征，不为儿童建立独立账号（账号只能由成年监护人以本人手机号注册），不基于儿童个人信息进行任何用户画像或定向推送，不向儿童展示个性化广告。
  • 3.4 关于头像照片：头像仅存储在设备本地或您主动开启云备份后的加密云端，不用于人脸识别，不用于任何算法训练。

🛡️四、存储、保护与内部管理

  • 4.1 存储位置与期限：儿童个人信息默认仅存储在您的设备本地；仅当监护人主动开启「云备份」时，才会通过 HTTPS 加密通道上传至我们位于中华人民共和国境内的服务器。我们不向境外提供儿童个人信息。存储期限为实现上述目的所必需的最短期限，删除成员或注销账号后即行删除。
  • 4.2 专人负责：我们已指定专人负责儿童个人信息保护，联系邮箱 1558406139@qq.com。
  • 4.3 最小授权与操作留痕：工作人员访问儿童个人信息须经负责人审批、留存访问记录，并采取技术措施避免非法复制、下载。
  • 4.4 加密与安全：传输与存储环节均加密处理，并定期开展安全审计与漏洞检测。
  • 4.5 泄露应急：发生或可能发生儿童个人信息泄露、毁损、丢失的，我们将立即启动应急预案、采取补救措施，及时以邮件或 APP 内通知方式告知监护人，并按规定向有关主管部门报告。

🤝五、委托处理、共享、转让与披露

  • 5.1 原则：我们不会向任何第三方出售、共享、转让或公开披露儿童个人信息，法律法规另有规定或取得监护人另行单独同意的除外。
  • 5.2 委托处理：仅当监护人开启「云备份」时，健康数据会存储于我们租用的境内云服务器（阿里云）。该委托处理受书面协议约束，受托方不得超出约定用途处理，不得转委托。我们在委托前已对受托方的安全保障能力进行评估。
  • 5.3 第三方 SDK：《康护APP隐私政策》所列的统计、推送、广告等第三方 SDK 不接触任何儿童的健康数据与成员档案信息。
  • 5.4 转让：因合并、分立、解散、被宣告破产需转移儿童个人信息的，我们将事先告知监护人；受让方将继续履行本规则义务，变更原有处理目的、方式的，将重新征得监护人同意。

⚖️六、监护人的权利与行使方式

监护人（以及已满 14 周岁的未成年人本人）可随时行使以下权利，无需付费、无需提供身份证件或手持照片等额外材料：

  • 6.1 查阅与复制：在「我的 → 成员管理 → 点击该成员」查阅全部档案信息；在「我的 → 账号管理 → 数据管理 → 导出数据」导出全部健康数据副本。
  • 6.2 更正：在「我的 → 成员管理 → 点击该成员」修改姓名、性别、生日、头像；点击任一条健康记录进入详情页即可修改数值。
  • 6.3 删除
    • 删除单条健康记录：点击该记录 → 右上角「删除」，即时生效。
    • 删除该儿童的全部信息：「我的 → 成员管理 → 删除成员」，其档案与名下全部健康记录一并删除，即时生效。
    • 删除云端副本：「我的 → 账号管理 → 数据管理 → 云备份 → 删除云端数据」。
    • 在下列情形下，即使您未主动操作，我们也将主动删除：我们违反法律法规或双方约定收集、使用儿童个人信息的；您撤回同意的；您注销账号的；服务终止的。
  • 6.4 撤回同意：删除该儿童的成员档案，即视为撤回对其个人信息处理的同意；也可发送邮件至 1558406139@qq.com 声明撤回。撤回后我们将停止处理并删除已收集的该儿童个人信息。
  • 6.5 注销账号：「我的 → 点击顶部账号卡片 → 账号管理 → 删除账号」，经绑定手机号短信验证后即时注销，账号下全部成员（含儿童）的信息在服务器后台一并删除或匿名化。
  • 6.6 响应时限：APP 内可直接操作的请求即时生效；需人工处理的请求，我们承诺自收到之日起15 个工作日内完成核查、处理并反馈结果。

💬七、投诉、举报与联系方式

  • 7.2 对外举报：如您发现有人通过本 APP 非法收集、使用、共享、转让、公开披露儿童个人信息，或对我们的答复不满意，可向网信、电信、公安、市场监管等主管部门举报，或向有管辖权的人民法院提起诉讼。
  • 7.3 运营者信息：开发者（运营者）为衡水青智科技有限公司。
