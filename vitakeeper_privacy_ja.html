VitaKeeper APP プライバシーポリシー

プライバシーポリシー
🔒 最終更新：2026年08月17日

VitaKeeper APPは、血圧、血糖、血中脂質、BMIデータの記録、健康リマインダー、家族メンバー管理、データ統計分析、OCR画像認識等の機能を提供する健康管理アプリケーションです。私たちはお客様の個人情報と健康データを非常に重視し、お客様の情報セキュリティを最大限に保護いたします。本プライバシーポリシーは関連する法律法規に基づいて策定され、私たちがどのようにお客様の情報を収集、利用、保存、保護するかを明確に説明いたします。

お客様が本プライバシーポリシーをお読みになり「同意して続行」をタップされるまでは、当社および本ポリシーに記載のいかなる第三者 SDK も、お客様の個人情報を一切収集せず、システム権限を要求せず、デバイス識別子を読み取りません。統計・プッシュ・クラッシュ監視等の第三者サービスは、すべてお客様の同意後にのみ初期化されます。

お客様が 14 歳未満のお子様、またはその保護者である場合は、「未成年者の個人情報保護規則」も併せてご確認ください：https://hs-qingzhi.github.io/support/vitakeeper_minor_privacy_en.html

📊第1条 情報収集の方法と範囲

  • 1.1 健康データ収集：お客様がVitaKeeper APPで血圧、血糖、血中脂質、BMI等の健康情報を記録する際、私たちは健康分析、トレンドリマインダー、レポート生成のために関連データを収集いたします。お客様はいつでもAPP内でご自身の健康データを確認、修正、削除することができます。
  • 1.2 基本デバイス情報：より安定した個別化されたサービスを提供するため、お客様がプライバシーポリシーに同意された後、デバイスハードウェア情報（デバイスモデル、オペレーティングシステムバージョン、デバイスシリアル番号等）およびネットワーク情報（IPアドレス、ネットワークタイプ等）を収集する場合があります。これらは統計、セキュリティリスク管理とサービス体験の最適化に使用されます。
  • 1.3 第三者サービス利用：一部の機能は第三者サービスに依存して実装される場合があります。これらのサービスは、ユーザーがプライバシーポリシーに同意した後にのみ実行されます。具体的には以下が含まれます：
    • 友盟統計サービス：APP利用状況統計とパフォーマンス最適化に使用されます。サービスはデバイス情報（デバイスモデル、オペレーティングシステムバージョン、ネットワークタイプ、IPアドレス）を収集する場合がありますが、お客様の健康データは収集しません。
    • 友盟プッシュサービス：お客様に健康リマインダーと重要な通知を送信するために使用され、APNs／Push token 等のデバイス識別情報を利用します。
    • Alibaba Cloud ACCS メッセージチャネル（パッケージ名 com.taobao.accs、上記の友盟プッシュ SDK に内蔵）：プッシュの常時接続を維持し、健康リマインダーを遅延なく届けるために使用されます。接続可否の判定と接続先の選択のため、ネットワーク状態情報（接続状態、ネットワーク種別（Wi-Fi／モバイル）、ローミング有無）および IP アドレスを読み取ります。健康データは収集しません。
    • Google モバイル サービス（GMS、Google 提供）（同上、iOS 版と Google Play 版でのみ有効）：Firebase プッシュの実行基盤を提供します。インストール済みアプリ情報（サービス可用性を判定するため Google Play ストア コンポーネント com.android.vending のバージョンのみを照会）およびデバイス識別情報を読み取ります。本サービスはお客様が本プライバシーポリシーに同意された後にのみ起動します。
    • オンデバイス文字認識（Google ML Kit Text Recognition）：血圧計・血糖計などの健康デバイスの画面や健康診断結果の数値を読み取るために使用されます。認識はすべてお客様の端末内で完結し、写真がサーバーへ送信されることも第三者へ提供されることもありません。
    • Firebase（Google提供）（iOS 版と Google Play 版でのみ有効。華為・栄耀・小米・OPPO・vivo・応用宝等の中国本土向け Android チャネル版では無効）：Firebase Cloud Messaging（プッシュ通知）およびFirebase Remote Config（リモート設定）を含みます。デバイス識別情報、IPアドレス、アプリのインストール情報を収集する場合があります。本サービスは中国本土域外で処理されます。「1.5 個人情報の越境提供」をご参照ください。
    • アプリ内課金（Apple StoreKit / Google Play Billing）：サブスクリプションと決済の処理に使用されます。取引はAppleまたはGoogleが直接管理し、当社はサブスクリプションのステータスと有効期限のみを受け取り、お客様の支払い情報にはアクセスしません。
  • 1.4 ユーザーフィードバックと苦情：お客様はAPPの「マイ」ページの「問題フィードバック」機能を通じてフィードバックや苦情を提出することができ、個人情報や健康データに関わる場合は、プライバシーポリシーに従って厳格に処理いたします。
  • 1.5 個人情報の越境提供
    • 適用範囲：越境提供が生じるのは iOS 版と Google Play 版のみです。華為・栄耀・小米・OPPO・vivo・応用宝・360・百度・豌豆莢等の中国本土向け Android チャネル版は Google サービスを有効化せず、個人情報を域外へ提供しません。
    • 域外の受領者：Google LLC（設立地：米国カリフォルニア州）。
    • 連絡先：https://support.google.com/policies；プライバシーポリシー https://policies.google.com/privacy
    • 目的：プッシュ通知の配信（Firebase Cloud Messaging）、バージョン更新等のリモート設定の取得（Firebase Remote Config）。
    • 方法：Google が域外のサーバーで受領し処理します。
    • 情報の種類：デバイス識別情報、IP アドレス、アプリのインストール情報。お客様の健康データ、メンバー情報、電話番号は含まれません。
    • お客様の権利：システム設定で通知権限をオフにする、またはアプリをアンインストールすることで上記の越境提供を撤回できます。1558406139@qq.com 宛のご連絡でも停止を求められます。

⚖️第4条 お客様の権利と行使方法

以下の各権利には、APP 内に対応する操作導線があります。行使にあたりカスタマーサポートへの連絡、費用、本人確認書類や本人確認書類を持った写真などの追加資料は一切不要です。

  • 4.1 開示・訂正
    • 健康データ：「ホーム」または各記録一覧で、血圧・血糖・血中脂質・BMI の任意の記録をタップして確認・修正できます。
    • メンバー情報（氏名・性別・生年月日・アイコン）：「マイ → メンバー管理 → 該当メンバーをタップ」。
    • データの写し：「マイ → その他 → データをエクスポート」。すべての健康データを JSON／CSV で書き出せます。
  • 4.2 削除
    • 個別の健康記録：該当記録を開き、右上の「削除」をタップ。即時反映されます。
    • メンバーと全記録：「マイ → メンバー管理 → メンバーを削除」。即時反映されます。
    • 端末内の全データ：アプリをアンインストールすると端末内の健康データはすべて削除されます。データはサーバーへ送信されないため、アンインストール後に当社が保持する写しはありません。
    • フィードバックと画像：「マイ → その他 → フィードバック → マイフィードバック」。
    • 上記の導線で削除できない場合は 1558406139@qq.com までご連絡ください。15 営業日以内に確認のうえ対応いたします。
  • 4.3 アカウントについて
    • 本アプリにアカウント機能はありません。登録は不要で、電話番号の収集も SMS 認証コードの送信も行わないため、「アカウントの削除」という操作自体が存在しません。
    • Premium の権利は App Store／Google Play のアカウントに紐付いており、当社とは無関係です。サブスクリプションの確認・解約・返金は各ストアのサブスクリプション設定で行ってください。
    • 情報を完全に消去するには、アプリをアンインストールしてください。健康データは端末内にのみ存在し、当社サーバーに写しはありません。
  • 4.4 同意の撤回
    • 本ポリシー全体への同意の撤回：アプリのアンインストールをもって撤回とみなします。または 1558406139@qq.com 宛に撤回のご連絡をいただければ、15 営業日以内に該当する取扱いを停止します。
    • カメラ権限：端末の「設定 → アプリ → 康護 → 権限 → カメラ → オフ」。オフでも手入力は可能です。
    • 通知権限：端末の「設定 → アプリ → 康護 → 通知 → オフ」、または「マイ → 健康リマインダー」でリマインダーをオフ。
    • 撤回は、撤回前に同意に基づいて行われた取扱いの適法性に影響しません。個別の権限を撤回すると該当機能はご利用いただけなくなりますが、APP の基本である端末内の健康記録機能には影響しません。
  • 4.5 対応期限：APP 内で直接操作できる訂正・削除は即時反映されます。人的対応を要するご請求（メールでの削除・同意撤回・写しの請求を含む）については、受領日から 15 営業日以内に確認・対応のうえご回答することをお約束します。

💬第8条 フィードバック機能における情報の取り扱い

アプリ内の「フィードバック」をご利用になる際、当社はお客様のフィードバックの受領・対応、お客様との連絡、製品の改善のためにのみ、以下の情報を収集・処理します：

  • 8.1 お客様が任意で提供する情報：フィードバック内容、画像、連絡先（任意）。連絡先は暗号化して保存します。
  • 8.2 問題特定のために自動的に付随する情報：アプリのバージョン、OS バージョン、端末モデル、言語、会員状態、現在のページ、および匿名の端末識別子（氏名や電話番号などの実際の身元は含みません）。送信時にアクセス IP も記録しますが、不正利用防止とセキュリティのためにのみ使用し、長期保存は行いません。
  • 8.3 保存と第三者：データは Alibaba Cloud（中国本土・北京）に保存されます。画像は Alibaba Cloud Object Storage（OSS）にアップロードされ、違反コンテンツを遮断するため Alibaba Cloud の DashScope 画像認識モデルによる機械審査を行います。この画像審査は当社による Alibaba Cloud への委託処理です。
  • 8.4 保存期間：画像は既定で 12 か月後に自動削除されます。テキストのフィードバックはチケット解決後 12 か月保存され、期限を過ぎると自動的に削除されます。
  • 8.5 お客様の権利：「マイフィードバック」内でご自身のすべてのフィードバック（画像を含む）を削除できます。送信後ただちに記録を削除し、画像はその後削除されます。
  • 8.6 非公開：本チャネルはお客様と開発者との間の非公開のサポートチケットであり、その内容が他のユーザーに公開されることはありません。
